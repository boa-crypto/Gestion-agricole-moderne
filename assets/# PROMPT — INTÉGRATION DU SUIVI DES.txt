# PROMPT — INTÉGRATION DU SUIVI DES STADES CULTURAUX DANS AGRIPRO

Tu travailles sur une plateforme agricole existante appelée AgriPro, développée en Python.

Ta mission est d'intégrer un système professionnel de SUIVI DES CULTURES PAR STADES PHÉNOLOGIQUES.

IMPORTANT :
Ne crée pas une fonctionnalité isolée.
Le système des stades doit être profondément intégré aux modules existants d'AgriPro :
Parcelles, Cultures, Campagnes, Interventions, Irrigation, Fertilisation, Traitements, Récoltes, Stocks, Personnel, Matériel, Rapports et Guide Agricole.

==================================================
1. OBJECTIF
==================================================

Permettre à AgriPro de suivre, pour chaque culture et chaque parcelle :

- le cycle de développement ;
- le stade actuel ;
- les stades précédents ;
- les stades suivants ;
- les dates d'observation ;
- la progression ;
- les opérations recommandées ;
- les interventions réalisées ;
- les anomalies ;
- les observations agronomiques ;
- l'historique phénologique.

Le système doit comprendre qu'il n'existe PAS un nombre universel de stades pour toutes les cultures.

Chaque culture doit disposer de son propre référentiel phénologique.

==================================================
2. RÈGLE FONDAMENTALE
==================================================

NE PAS utiliser une liste globale identique pour toutes les cultures.

Exemple :

Blé :
Germination → Levée → Tallage → Montaison → Épiaison → Floraison → Remplissage → Maturation

Tomate :
Germination → Levée → Croissance végétative → Floraison → Nouaison → Développement du fruit → Véraison → Maturation

Olivier :
Repos végétatif → Reprise → Floraison → Nouaison → Développement du fruit → Durcissement du noyau → Véraison → Maturation

Vigne :
Dormance → Débourrement → Croissance végétative → Floraison → Nouaison → Fermeture de la grappe → Véraison → Maturation → Récolte

Chaque culture doit donc posséder son propre cycle.

5. BBCH
==================================================

Lorsque cela est pertinent, permettre d'associer un code BBCH au stade.

Exemple :

Blé :
BBCH 10 → premières feuilles
BBCH 21 → début du tallage
BBCH 30 → début montaison
BBCH 51 → début épiaison
BBCH 61 → début floraison
BBCH 71 → développement du grain

NE PAS imposer BBCH à toutes les cultures si le référentiel utilisé n'est pas approprié.

Prévoir :

- système_phénologique ;
- code_bbch ;
- stade_local ;
- description.

L'interface utilisateur doit afficher un vocabulaire agricole compréhensible.
